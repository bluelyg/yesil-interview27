# 2027 수시면접 대비 · 상원고

고등학교 3학년 수시 면접을 준비하는 웹앱(단일 HTML, PWA). 사전 준비 가이드, 대학별 기출·평가요소 검색, 마이크 녹음 모의면접과 자동 피드백, 인문/자연 면접 일정 달력(D-day)을 한 곳에서 제공합니다.

- **기획·제작**: 상원고등학교 교사 유은실
- **현재 버전**: v1.8 (수록 8개교)

## 바로 실행
`index.html`을 브라우저(PC/모바일)에서 열면 됩니다. 별도 설치·서버 불필요(규칙 기반, 오프라인 동작).
- 음성 인식 피드백은 **Chrome**(PC·안드로이드)에서 동작합니다.
- 아이폰은 실시간 인식이 안 되므로 ‘녹음 파일로 분석’(브라우저 내장 Whisper) 또는 타이머로 이용합니다. (마이크·변환은 https 배포 주소에서만 작동)

## 배포 (링크 공유)
`index.html`을 GitHub Pages 또는 Netlify에 올리면 https 주소가 생성됩니다. 그 주소를 카톡 등으로 공유하세요.
- GitHub Pages: 저장소 **Settings → Pages → Branch: main / (root)**.

## 폴더 구조 / 개발 방법
개발·데이터 편집·대학 추가·남은 작업은 **[PROGRESS.md](PROGRESS.md)** 를 참고하세요.
요약: 화면은 `면접대비앱.html`, 데이터는 `*.json`을 편집한 뒤 `index.html`의 `<script id="seed">` 블록에 재주입해 빌드합니다.

## 라이선스/사용
상원고 교내 면접 지도 목적의 자료입니다. 대학별 문항·평가요소는 각 대학 ‘선행학습 영향평가 보고서(2026)’ 기준이며, 모범답변·키워드는 학습 지도용으로 작성했습니다. 실제 지원 시 각 대학 모집요강을 확인하세요.
